    Colour scales¶

    The colour scales of the force viewer, for every front end that colours tensions and pressures.

    The Polyscope viewer (foambryo.viewing), foambryo view --colour-bars and the napari plugin colour with these functions, so one value has one colour in all of them, and a colour bar spans exactly the range the colours were clipped to:

    • tensions: coolwarm (TENSION_COLOUR_MAP: blue for low, light grey for the mean, red for high), over a range centred on the mean of the finite tensions and symmetric around it, reaching the farther of the alpha and 1 - alpha quantiles (tension_colour_range, tension_colour_fractions, tension_colours);
    • pressures: magma reversed and trimmed to its 10-90 % range (PRESSURE_COLOUR_MAP, PRESSURE_COLOUR_MAP_RANGE: no pressure is black or near-white, so none vanishes on a black or a white background), from 0 to the 1 - alpha quantile of the finite pressures over the surface's triangles (surface_pressure_colour_upper, pressure_colour_fractions, pressure_colours);
    • other per-interface quantities (a seed spread, a residual): jet between the alpha and 1 - alpha quantiles (quantile_colour_range, clipped_colour_fractions, quantity_colours);
    • undetermined values (nan): UNDETERMINED_COLOR, green, outside every map; a viewer that can draw outlines draws an undetermined interface as its outline in this green, without fill;
    • crop faces: see-through glass, CROP_FACE_COLOR at CROP_FACE_OPACITY with edges in CROP_FACE_EDGE_COLOR;
    • the backgrounds a viewer offers, by name (BACKGROUND_COLOURS: black, dark grey, light grey, white).

    alpha is DEFAULT_CLIP_QUANTILE (0.05) unless given. save_colour_bars writes the bars to an image file and returns the values at their ends (ColourBarRanges). This module needs matplotlib (installed by foambryo[viewing]), but neither Polyscope nor a display. The functions are implemented in foambryo._colour_scales; this module is their public interface.

    pressure_colours ¶

    pressure_colours(fractions: NDArray[float64]) -> NDArray[np.float64]

    RGB colours of pressure fractions (pressure_colour_fractions), as every front end draws them.

    A fraction x in [0, 1] is magma(lo + (hi - lo) x), (lo, hi) = PRESSURE_COLOUR_MAP_RANGE (0.1, 0.9): 0 (the top of the range) is dark purple, 1 (a pressure of 0 or below) light orange, and no pressure is black or near-white. nan is UNDETERMINED_COLOR.

    save_colour_bars ¶

    save_colour_bars(mesh: DcelData, dict_tensions: dict[tuple[int, int], float], dict_pressures: dict[int, float] | None, path: str | PathLike[str], alpha: float = DEFAULT_CLIP_QUANTILE, *, tension_label: str = 'Surface tension', pressure_label: str = 'Pressure') -> ColourBarRanges

    Write the colour bars of the force viewer's surface colours to an image file.

    One horizontal bar per quantity, each spanning exactly the range the viewer colours over (colour_bar_ranges), drawn with the viewer's own colour function, with its two end values written under it:

    • surface tension: coolwarm, centred on the mean of the finite tensions (one per interface; light grey), symmetric, its half-width the farther of the alpha and 1 - alpha quantiles from the mean (tension_colour_range); the viewer draws tensions beyond either end in the end's colour; the bar's middle tick is the mean;
    • pressure: magma reversed (light for low) and trimmed to its 10-90 % range, so that neither end is black or near-white, from 0 to the 1 - alpha quantile of the finite pressures over the mesh's triangles, each carrying the pressure of the higher-labelled of its two materials, as on the viewer's surface; negative pressures are drawn as 0.

    A green swatch, "undetermined", is added when any value is nan, and a glass swatch, "crop face", when the mesh has crop faces. The viewer's graph view (cell nodes) colours pressures on this same scale (surface_pressure_colour_upper).

    Headless: matplotlib's non-interactive canvas, no window, no Polyscope.

    Parameters:

    Name Type Description Default
    mesh DcelData

    the mesh the values belong to.

    		 required
    dict_tensions dict[tuple[int, int], float]

    tension per interface ((label_1, label_2) -> tension, label_1 < label_2).

    		 required
    dict_pressures dict[int, float] | None

    pressure per material (label -> pressure, 0 = medium), or None for the tension bar only.

    		 required
    path str | PathLike[str]

    the image file; matplotlib chooses the format from the suffix (.png, .pdf, .svg).

    		 required
    alpha float

    quantile clipped at each end, the viewer's alpha (default 0.05).

    		 DEFAULT_CLIP_QUANTILE
    tension_label str

    the tension bar's title (for example with a unit). Keyword-only.

    		 'Surface tension'
    pressure_label str

    the pressure bar's title. Keyword-only.

    		 'Pressure'

    Returns:

    Name Type Description
    ColourBarRanges ColourBarRanges

    the values at the ends of each bar (pressure is None when no pressure bar was
    ColourBarRanges

    drawn).

    Raises:

    Type Description

    if no tension is finite (there is no scale to draw), or matplotlib does not know the file's suffix.

    surface_pressure_colour_upper(mesh: DcelData, dict_pressures: dict[int, float], alpha: float = DEFAULT_CLIP_QUANTILE, *, scattered: bool = False) -> np.float64 | None

    The top of the viewer's pressure scale, for every view that colours pressures.

    tension_colour_range ¶

    tension_colour_range(values: NDArray[float64], alpha: float = DEFAULT_CLIP_QUANTILE, *, centre: float | None = None) -> tuple[float, float]

    The range the viewers colour tensions over: centred on the mean tension, symmetric around it.

    The centre is the mean of the finite tensions, which is mean_tension (1 by default) for every method that meets its gauge exactly (infer_tensions; per junction-graph component, so also over several components). The half-width is the larger of the distances from the centre to the alpha and the 1 - alpha quantiles, so that both quantiles lie within the range and a tension equal to the mean is drawn in the map's middle colour (light grey).

    Parameters:

    Name Type Description Default
    values NDArray[float64]

    the tensions, one per interface; nan values take no part.

    		 required
    alpha float

    quantile at each end, in [0, 0.5) (the viewer's alpha, default 0.05).

    		 DEFAULT_CLIP_QUANTILE
    centre float | None

    the centre instead of the mean (for example a known mean_tension). Keyword-only.

    		 None

    Returns:

    Name Type Description
    tuple tuple[float, float]

    (centre - half, centre + half). With every finite tension equal, (centre, centre).

    Raises:

    Type Description
    ValueError

    if no tension is finite.
