    Curvature¶

    Mean curvature of a mesh's interfaces, from the cotangent Laplacian, as the Laplace pressure methods read it.

    Curvatures are in inverse mesh length units. An interface all of whose vertices lie on junction lines has no curvature (nan); see foambryo.pressure_inference.UndeterminedPressureWarning.

    A 2-D mesh (foambryo.PlanarMesh, delaunay-watershed-2d's DCEL_Data, a (points, segments, labels) triple or a (vertices, edges) pair) is read in 2D by compute_curvature_interfaces and compute_curvature_vertices_cotan: the curvature of each interface (a curve has one curvature, which takes the place of the surface's 2 H in Laplace's law), from the circle the 2-D pressures read or from the vertex curvatures, and the curvature at each vertex from the cotangent Laplacian's 1-D form; definitions, signs and derivation in foambryo._planar_curvature_and_stress. The Gaussian curvature has no 2-D counterpart.

    Sacha Ichbiah, 2021. Matthieu Perez, 2024.

    compute_laplacian_cotan ¶

    compute_laplacian_cotan(points: NDArray[float64], triangles: NDArray[int64]) -> tuple[NDArray[np.float64], NDArray[np.float64]]

    Laplacian computation.

    Consider a mesh M = (V, F), with verts of shape Nx3 and faces of shape Mx3. The Laplacian matrix L is a NxN matrix such that LV gives a matrix of vectors: LV[i] gives the normal scaled by the discrete mean curvature. For vertex i, assume S[i] is the set of neighboring vertices to i, a_ij and b_ij are the "outside" angles in the two triangles connecting vertex v_i and its neighboring vertex v_j for j in S[i], as seen in the diagram below. .. code-block:: python a_ij /\ / \ / \ / \ v_i /________\ v_j \ / \ / \ / \ / \/ b_ij The definition of the Laplacian is LV[i] = sum_j w_ij (v_j - v_i) For the uniform variant, w_ij = 1 / |S[i]| For the cotangent variant, w_ij = (cot a_ij + cot b_ij) / (sum_k cot a_ik + cot b_ik) For the cotangent curvature, w_ij = (cot a_ij + cot b_ij) / (4 A[i]) where A[i] is the sum of the areas of all triangles containing vertex v_i. There is a nice trigonometry identity to compute cotangents. Consider a triangle with side lengths A, B, C and angles a, b, c. .. code-block:: python c /|\ / | \ / | \ B / H| \ A / | \ / | \ /a_____|_____b\ C Then cot a = (B^2 + C^2 - A^2) / 4 * area We know that area = CH/2, and by the law of cosines we have A^2 = B^2 + C^2 - 2BC cos a => B^2 + C^2 - A^2 = 2BC cos a Putting these together, we get: B^2 + C^2 - A^2 2BC cos a _______________ = _________ = (B/H) cos a = cos a / sin a = cot a 4 * area 2CH [1] Desbrun et al, "Implicit fairing of irregular meshes using diffusion and curvature flow", SIGGRAPH 1999. [2] Nealan et al, "Laplacian Mesh Optimization", Graphite 2006.

    compute_curvature_vertices_cotan ¶

    compute_curvature_vertices_cotan(mesh: DcelData) -> tuple[NDArray[np.float64], NDArray[np.float64], NDArray[np.float64]]

    Return the mean curvature at every vertex along with other unidentified data.

    A 2-D mesh gives the 2-D form, (|K_i|, 1 / l_i, K_i): the magnitude of the curvature vector of the cotangent Laplacian's 1-D form (K_i = (t_2 - t_1) / l_i, exact on a circle sampled at equal steps), the inverse dual length and the vector (n, 2) in (row, column), pointing to the centre of curvature; nan at the junctions, the ends of the interfaces and the image border's vertices (foambryo._planar_curvature_and_stress.vertex_curvatures).

    compute_curvature_interfaces ¶

    compute_curvature_interfaces(mesh: DcelData, weighted: bool = True, *, reading: str | None = None) -> dict[tuple[int, int], float]

    Compute the mean curvature on the interfaces of the mesh.

    The vertex mean curvature of the cotangent Laplacian, signed by the vertex normal, averaged over each interface's vertices that are not on a junction line. Positive when the centre of curvature lies on the side of the interface's second label: P_a - P_b = -2 H_ab T_ab (a sphere of label 1 in the medium 0 has H_01 = +1/R).

    A 2-D mesh gives each interface's curvature kappa_ab in the same sense, with p_a - p_b = -gamma_ab kappa_ab (a disk of label 1 in the medium has kappa_01 = +1/R), read from the circle the 2-D pressures fit (reading="arc", the default) or from the vertex curvatures ("local"); the module foambryo._planar_curvature_and_stress gives the definitions and the derivation.

    Parameters:

    Name Type Description Default
    mesh DcelData

    the mesh, 3-D or 2-D.

    		 required
    weighted bool

    weight each vertex by its area (PressureComputationMethod. WeightedLaplace) rather than equally (Laplace); in 2D, each vertex by its dual length ("local") or each piece of an interface by its length ("arc"). Defaults to True.

    		 True
    reading str | None

    how the curvature is read: in 3D "cotan" (the only reading), in 2D "arc" or "local". Defaults to None: "cotan" in 3D, "arc" in 2D. Keyword-only.

    		 None

    Returns:

    Type Description
    dict[tuple[int, int], float]

    dict[tuple[int, int], float]: interface (label_1, label_2) -> mean curvature, in inverse mesh length units; nan for an interface all of whose vertices lie on junction lines (in 2D, one the reading gives no curvature).

    Raises:

    Type Description
    ValueError

    for a reading the mesh's dimension does not have.
