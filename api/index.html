    API reference¶

    Generated from the docstrings. The names exported by foambryo itself are listed in the package's __init__; the modules below hold them.

    module what
    foambryo.io dcel_mesh_from_segmentation_mask, dcel_mesh_from_file, reconstruct_mask
    foambryo.dcel DcelData: vertices, triangles, labels, crop faces, cut cells
    foambryo.tension_inference infer_tensions and its variants, TensionComputationMethod
    foambryo.pressure_inference infer_pressures, PressureComputationMethod
    foambryo.force_inference infer_forces, infer_tensions_then_pressures
    foambryo.seed_ensembles infer_tensions_over_seeds
    foambryo.crop_faces crop faces, cut cells and their warnings
    foambryo.linear_solves solver, SolveDiagnostics, save_solve_diagnostics
    foambryo.junction_graph components, undetermined interfaces, the exact normalisation
    foambryo.uncertainty infer_tensions_with_uncertainty, compute_inference_diagnostics
    foambryo.second_order_angle_reading angle_reading
    foambryo.wedge_refusal refusal, WedgeRefusal, refusal_report
    foambryo.per_edge_tension_inference YoungDupreLocal
    foambryo.force_balance_inference ForceBalance*, infer_force_balance
    foambryo.reconstruction_cost the time and memory estimate
    foambryo.segmentation_masks reading and checking masks, the mask report
    foambryo.results the tables and the run record of the command
    foambryo.colour_scales the viewers' colours
    foambryo.viewing plot_force_inference, view_mask, save_colour_bars
    foambryo.geometry areas, volumes, angles and their derivatives
    foambryo.curvature mean and Gaussian curvatures
    foambryo.validation mesh integrity and force-balance checks
