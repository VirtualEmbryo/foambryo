    The mesh¶

    The mesh every inference reads: DcelData, a multimaterial triangle mesh as a doubly connected edge list.

    A DcelData holds the vertices, the triangles with the two materials each separates, and the half-edge structure the geometry (foambryo.geometry, foambryo.curvature) walks. Build one with foambryo.dcel_mesh_from_segmentation_mask, foambryo.dcel_mesh_from_file or foambryo.dcel_mesh_from_multimaterial_mesh.

    Sacha Ichbiah, 2021. Matthieu Perez, 2024.

    DcelData ¶

    DcelData(points: NDArray[float64], triangles: NDArray[int64], labels: NDArray[int64], *, crop_faces: NDArray[bool_] | NDArray[integer] | None = None, source_spacing: tuple[float, float, float] | None = None)

    A multimaterial triangle mesh as a doubly connected edge list (DCEL): faces, half-edges and vertices.

    Conventions: label 0 is the exterior medium; every triangle's labels are stored as material_1 < material_2, its winding flipped to match (_normalize_label_order), so an interface is keyed (label_1, label_2) with label_1 < label_2; coordinates are in the mesh's own length unit (voxels, or the unit of the spacing the mesh was reconstructed with).

    Attributes:

    Name Type Description
    v NDArray[float64]

    vertex positions, (nv, 3), unused vertices removed.
    f NDArray[int64]

    triangles and labels, (nf, 5) rows (v0, v1, v2, material_1, material_2), in the input's row order.
    materials NDArray[int64]

    the labels present, sorted (0 first when the medium is).
    n_materials int

    their number.
    crop_faces NDArray[bool_]

    (nf,), True on the crop faces (all False without).
    source_spacing tuple[float, float, float] | None

    the source mask's voxel size, if recorded.
    vertices list[Vertex]

    the DCEL's vertex records, aligned with v.
    half_edges list[HalfEdge]

    the DCEL's half-edge records.
    faces list[Face]

    the DCEL's face records, aligned with the rows of f.

    Take a multimaterial mesh as input.

    Parameters:

    Name Type Description Default
    points NDArray[float64]

    Mesh vertex positions, shape (nv, 3).

    		 required
    triangles NDArray[int64]

    Triangles as vertex indices, shape (nf, 3).

    		 required
    labels NDArray[int64]

    The two materials each triangle separates, shape (nf, 2). A triangle's stored winding must put its right-hand-rule normal on the second label's side, i.e. point outward from the first — see _normalize_label_order for why, and for what goes wrong silently when a mesh from an outside source violates it.

    		 required
    crop_faces NDArray | None

    which triangles are crop faces: faces on the boundary of the imaged volume, where the tissue was cut by the crop rather than bounded by the medium. A boolean mask of shape (nf,) or the row indices of the crop faces, aligned with triangles. Keyword-only. Defaults to None, no crop face. A crop face keeps its labels (0, c); every inference method keeps it, and every junction edge and vertex that touches it, out of its equations, leaves the interfaces made only of crop faces out of its tension map, and reports the pressure of a cut cell as nan. See foambryo.crop_faces.

    		 None
    source_spacing tuple[float, float, float] | None

    the voxel size of the mask the mesh was made from, along the mask's axes 0, 1, 2, when the mesh records it: delaunay-watershed-3d's construct_mesh_in_physical_units writes it in the .rec file, dcel_mesh_from_file reads it, and dcel_mesh_from_segmentation_mask sets it when given a spacing. Keyword-only. Defaults to None, unknown. It changes nothing: the mesh is already in physical units, and no inference reads it. It is kept so that a mesh says which voxels it came from.

    		 None

    Raises:

    Type Description
    ValueError

    If any triangle carries the same material on both sides, or if crop_faces is not a mask or a set of rows of triangles, or names a triangle that does not carry the medium label 0, or if source_spacing is not three positive finite numbers.

    source_anisotropy property ¶

    source_anisotropy: float | None

    Longest over shortest source voxel size (1.0 for cubic voxels); None when the spacing is unknown.

    has_crop_faces property ¶

    has_crop_faces: bool

    Whether any triangle is a crop face. When False, no inference method applies a crop-face rule.

    crop_vertices property ¶

    crop_vertices: NDArray[int64]

    Sorted keys of the vertices that lie on a crop face (empty without crop faces).

    cut_cells property ¶

    cut_cells: tuple[int, ...]

    The cells the crop cuts: a cell with a crop face or with a vertex on one, sorted.

    Their volume and part of their surface lie outside the imaged volume, so a pressure inferred for them is not a measurement: the pressure methods report it as nan.

    crop_interfaces property ¶

    crop_interfaces: tuple[tuple[int, int], ...]

    Interfaces (0, c) all of whose triangles are crop faces, sorted.

    They are the crop itself, not a contact between a cell and the medium, so they carry no tension: no inference method gives them an unknown's value, and the tension maps leave them out. An interface (0, c) with crop faces and real contact with the medium keeps its tension, which then describes the real contact only.

    update_graph_with_scattered_values ¶

    update_graph_with_scattered_values(graph: Graph, mesh: DcelData) -> networkx.Graph

    Move the graph to the mesh's scattered ("exploded") view, from its unexploded positions.

    Each cell node, and the vertices of each interface with the medium, move by the displacement of their cell (mesh.clusters_displacements). Call it after mesh.compute_scattered_arrays(coeff). Every node then sits at its exploded cell's barycentre (up to rounding), and an interface with the medium moves with its cell; an interface between two cells does not move (its edge in the graph view is drawn between the two nodes).

    The positions are computed from the graph's unexploded ones each time, into new arrays: they are recorded in graph.graph["unexploded_centroid"] and graph.graph["unexploded_verts"] at the first call, so that calling it again on the same graph (a new coefficient) does not add a second displacement, and the arrays the graph was built with (mesh.centroids itself for the nodes) are never modified.

    Parameters:

    Name Type Description Default
    graph Graph

    the mesh's graph (compute_networkx_graph), modified and returned.

    		 required
    mesh DcelData

    the mesh, after compute_scattered_arrays.

    		 required

    Returns:

    Type Description
    Graph

    networkx.Graph: graph, its "centroid" node attributes and "verts" edge attributes moved.
