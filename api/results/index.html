    Result files¶

    The result files of the foambryo command, for every front end that writes or reads them.

    foambryo infer and foambryo infer-over-seeds write CSV tables and a JSON run record, run.json (schema 1); the napari plugin writes the same files. Both use this module, so a table written by either reads back as the library's 64-bit numbers, and a run record has the same keys:

    • the tables: write_tension_table / read_tension_table, write_pressure_table / read_pressure_table, the seed ensemble's write_ensemble_tension_table and write_per_seed_tension_table and their readers, the solve diagnostics' write_solve_table / read_solve_table (solves.csv, one row per linear solve) and write_spectra (spectra.npz), and format_float, the shortest decimal string that reads back as the same float. The file names are TENSION_TABLE, PRESSURE_TABLE, SOLVE_TABLE, SPECTRA, RUN_RECORD, ...; the readers and writers take a pathlib.Path;
    • the run record: infer_run_record and ensemble_run_record build it, write_run_record writes it, read_run_record reads it; RUN_RECORD_SCHEMA is its schema number;
    • what a run record names: the methods by their command-line spellings (option_name, TENSION_METHODS, PRESSURE_METHODS, DIAGNOSTICS), the versions (library_versions), and the warnings raised, each once with its count (WarningCollector).

    The tables and the record's writers are implemented in foambryo._result_tables; this module is their public interface. Changing a column, or a run-record key's name or meaning, makes a new schema.

    WarningCollector ¶

    WarningCollector()

    Catch the warnings raised inside a block, and count each distinct one.

    Use it as a context manager (with WarningCollector() as collector: ...). DeprecationWarning, PendingDeprecationWarning, ImportWarning and ResourceWarning are ignored inside the block (neither shown nor counted); every other warning is caught, wherever it is raised, rather than once per code location, so a count is the number of times it was raised. Caught warnings are not shown. After the block, summary holds one entry per distinct warning (same category and message), {"category": ..., "message": ..., "count": ...} with the category's class name, in the order they were first raised: a run record's warnings.

    Start with an empty summary.

    format_float(value: float) -> str

    The shortest decimal string that reads back as the same float (nan, inf, -inf as such).

    json_safe ¶

    json_safe(value: Any) -> Any

    Convert numpy scalars and arrays, tuples and non-finite floats into plain JSON values.

    Non-finite floats become the strings "nan", "inf", "-inf": JSON has no such numbers, and a reader that meets a bare NaN token (which Python's json would write) may refuse the file.

    write_solve_table(path: Path, records: list[Any]) -> None

    Write solves.csv: one row per linear solve, in the order they ran (SOLVE_COLUMNS).
